# Brightfold link page

A single static page for the @brightfold.co TikTok bio. Four buttons, one per shop, each with a UTM-tagged storefront link.

- Soft Coat Co, Road Tidy, Mat & Mend, Maison Larder
- Descriptions taken from each store’s public homepage meta description (shipping claims omitted)
- No analytics, no third-party scripts, no fonts from a CDN

UTM on every button: `utm_source=tiktok&utm_medium=social&utm_campaign=bio&utm_content=<store>_bio`
